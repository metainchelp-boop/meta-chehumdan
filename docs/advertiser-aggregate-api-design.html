⑤ 구현 범위 (v1 / 추후)

  • v1 ✓신규 mc_advertiser_api.php (기존 토큰 API 복제, 사이트 기능 불변)
  • v1 ✓광고주 목록 + 광고주별 누적 총계·회차별 표·리뷰 링크
  • v1 ✓전산: 광고주 ↔ supply_no 1클릭 매핑 + 대시보드 API 병합 + 체험단 카드 표시
  • 추후 ○유입·노출 트래픽 세부(주 단위 분할 테이블 nfor_traffic_YYYY_WW) — 캠페인마다 주 테이블을 찾아야 해 무거움. v1은 조회수(cp_click)·퍼널까지, 트래픽 세부는 다음 단계
  • 추후 ○광고주 단위 공개 정적 보고서(기존 campaign_report_share 방식을 업체 단위로 확장 — 선택)
🔐 토큰: 기존 API처럼 서버에만 있는 상수로 인증(전산↔메타체험단 서버 간 통신). 광고주에게 노출되는 건 전산 공유링크 토큰이고, 이 API 토큰은 외부에 안 나갑니다.
